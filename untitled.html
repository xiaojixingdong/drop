第1章 代码是什么

代码就是写给电脑看的命令。你写一句，它做一件事。

JavaScript 是一种代码，它住在浏览器里。不需要安装任何东西，浏览器自带。

第一句命令

写在 HTML 的 <script> 里
console.log("你好");

这行的意思：把“你好”打印出来。

说明console.log(...) 就是“把括号里的东西打印出来”。引号里的字是内容，引号本身不显示。

多写几行

console.log("我叫小明");
console.log("我13岁");
console.log(3 + 5);

每句后面要有分号 ;。文字要加引号，数字不用。第三行会输出 8。

注释

// 单行注释，浏览器会跳过
console.log("能看到");  // 这行后面的也是注释
/*
  多行注释
  可以写好几行
*/
注释的作用写给未来的自己看。三个月后你忘了这段代码干嘛的，注释能救你。

出错了会怎样

consol.log("你好");
// Uncaught ReferenceError: consol is not defined

意思是：我不认识 consol 这个东西。先看错误第一行，它告诉你哪里错。

新手最常犯的三个错1. 拼错单词 consle、consol。2. 用了中文引号“你好”，要用英文引号 "你好"。3. 忘了分号（现代 JS 大部分情况不报错，但养成写分号的习惯）。
纸上练习1. 写出打印你名字、年龄、最喜欢食物的三行代码。2. 写出打印 100 * 100 的代码。3. 把 console.log("你好") 前面加 //，这行还会打印吗？

第2章 变量

变量是一个盒子。你把数据装进去，起个名字，以后用名字找到它。

let 和 const

let age = 18;        // 可以改
const name = "小明";  // 不可重新赋值

age = 19;       // 可以，age 变成 19
name = "小红";  // 报错：Assignment to constant variable
口诀值会变用 let，值不变用 const。优先用 const。

const 声明的对象内部可以改

const 锁的是“盒子本身”，不是盒子里的东西。

const user = { name: "小明" };
user.name = "小红";       // 可以，改的是盒子里的属性
console.log(user.name);   // "小红"

user = { name: "小李" };  // 报错，这是换盒子

变量命名规则

  • 只能用字母、数字、下划线、美元符号
  • 不能以数字开头：1name 错，name1 对
  • 区分大小写：age 和 Age 是两个不同的变量
  • 不能用保留字：let、const、if、for 不能当变量名
  • 用有意义的名字：userName 比 a 好

一次声明多个

let a = 1, b = 2, c = 3;
console.log(a + b + c);  // 6
纸上练习1. 声明一个变量存你的年龄，用 let，打印它。2. 声明一个常量存你的名字，用 const，打印它。3. 尝试给常量重新赋值，写出报错信息是什么。

第3章 类型

JS 的每个值都有类型。最常用的几种：

原始类型

typeof "hello"    // "string"    文字
typeof 42         // "number"    数字
typeof 3.14       // "number"    小数也是 number
typeof true       // "boolean"   真/假
typeof undefined  // "undefined" 未定义
typeof null       // "object"    历史 bug
记住typeof null 返回 "object"，这是 JS 最早的设计失误。判断 null 要用 x === null。

string 字符串

"双引号"
'单引号'
`反引号，可以插 ${变量}`

三种都一样，但反引号能插变量：

const name = "小明";
const age = 13;
console.log(`我叫 ${name}，今年 ${age} 岁`);
// 我叫 小明，今年 13 岁

number 数字

100       // 整数
3.14      // 小数
1e3       // 1000，科学计数法
0x10      // 16，十六进制
NaN       // 不是数字，比如 0 / 0
Infinity  // 无穷大，比如 1 / 0

boolean 布尔

只有两个值：true 和 false。

类型转换

Number("123")   // 123，字符串转数字
String(123)     // "123"，数字转字符串
Boolean(0)      // false
Boolean(1)      // true
Boolean("")     // false
Boolean("abc")  // true
假值以下都是 false：false、0、""（空字符串）、null、undefined、NaN。其他都是 true。
纸上练习1. 用 typeof 判断 "abc"、123、true、null 的类型。2. 写出用模板字符串输出“我叫X，今年Y岁”的代码。

第4章 比较和条件

程序经常判断“是不是”。结果只有两个：true 和 false。

比较运算符

1 === "1"   // false，类型不同，值相同
1 == "1"    // true，宽松相等，别用
1 !== "1"   // true，严格不等
1 != "1"    // false，宽松不等
1 < 2       // true
2 >= 2      // true
null === undefined  // false
null == undefined   // true
永远用 ===== 会做类型转换，结果经常出乎意料。日常写代码只用 === 和 !==。

?? 和 ?.

const input = null;
const name = input ?? "匿名";  // "匿名"

const user = { address: null };
const city = user?.address?.city ?? "未知"; // "未知"

?? 只在左边是 null 或 undefined 时给默认值。?. 安全访问嵌套属性，不会报错。

if / else

const score = 85;

if (score >= 90) {
  console.log("A");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}
// 输出：及格

三元运算符

const score = 85;
const type = score >= 60 ? "过" : "挂";
console.log(type); // "过"

格式：条件 ? 真时的值 : 假时的值。适合一行写完的二选一。

switch

const day = 3;
let name;

switch (day) {
  case 1: name = "周一"; break;
  case 2: name = "周二"; break;
  case 3: name = "周三"; break;
  default: name = "未知";
}
console.log(name); // "周三"

多个固定值比较时，switch 比一堆 if 清晰。别忘了 break，不然会一直往下跑。

纸上练习1. 判断 1 === "1" 和 1 == "1" 的结果。2. 用 if/else 写：年龄 ≥ 18 输出“成年”，否则“未成年”。3. 用三元重写它。

第5章 循环

循环让代码重复跑。

for 循环

for (let i = 0; i < 5; i++) {
  console.log(i);
}
// 输出：0 1 2 3 4

拆开看：let i = 0 从 0 开始；i < 5 只要小于 5 就继续；i++ 每次加 1。

for...of

const fruits = ["苹果", "香蕉", "橘子"];
for (const fruit of fruits) {
  console.log(fruit);
}
// 输出：苹果 香蕉 橘子

forEach

const nums = [1, 2, 3];
nums.forEach(n => {
  console.log(n);
});
// 输出：1 2 3

while 循环

let i = 0;
while (i < 3) {
  console.log(i);
  i++;
}
// 输出：0 1 2

条件为真就一直跑。注意别写成死循环（条件永远为真，浏览器会卡死）。

break 和 continue

for (let i = 0; i < 10; i++) {
  if (i === 5) break;      // 到 5 就停
  console.log(i);          // 0 1 2 3 4
}

for (let i = 0; i < 5; i++) {
  if (i === 2) continue;   // 跳过 2
  console.log(i);          // 0 1 3 4
}
纸上练习1. 用 for 打印 1 到 10。2. 把 [1,2,3,4,5] 里每个数乘以 2 打印。3. 用 while 打印 10 到 1。

第6章 函数

函数就是给一段代码起个名字，以后叫这个名字就能跑这段代码。

函数定义与调用

function add(a, b) {
  return a + b;
}
console.log(add(2, 3)); // 5

a 和 b 是参数，return 返回结果。没写 return 的函数返回 undefined。

默认参数

function greet(name = "陌生人") {
  return "你好，" + name;
}
console.log(greet());       // "你好，陌生人"
console.log(greet("小明")); // "你好，小明"

箭头函数

const add = (a, b) => a + b;
const square = n => n * n;

console.log(add(2, 3));    // 5
console.log(square(4));    // 16

一行能写完的，不用写 return。多行的要加 {} 和 return：

const add = (a, b) => {
  const sum = a + b;
  return sum;
};

函数可以作为参数

function run(fn) {
  fn();
}

run(() => console.log("被调用了"));
// 输出：被调用了
纸上练习1. 写函数 double(n)，返回 n×2。2. 用箭头函数重写。3. 写函数 max(a,b)，返回较大的数。

第7章 闭包和 this

闭包

函数记住了外面的变量，即使外部函数已经执行完。

function counter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}

const c = counter();
console.log(c()); // 1
console.log(c()); // 2
console.log(c()); // 3

counter 已经跑完，但内部函数还记得 count。这就是闭包。

为什么重要app.js 里 Utils.api 记住 State.token，就是靠闭包。没有闭包，函数每次调用都从零开始。

this 简讲

const user = {
  name: "小明",
  say() {
    console.log(this.name);
  }
};

user.say(); // "小明"  this 指向 user

const fn = user.say;
fn();       // undefined  this 丢了

this 是“谁调用我，我就是谁”。把方法赋值给变量再调用，this 就丢了。

箭头函数没有自己的 this

const obj = {
  name: "小明",
  say: () => {
    console.log(this.name); // undefined
  }
};

箭头函数继承外层的 this。回调里用箭头函数，更安全。app.js 大量用箭头函数就是这个原因。

纸上练习1. 写一个 adder(n)，返回一个每次都加 n 的函数。用它生成“加 5”的函数，调用两次看结果。2. 写对象 {name:"A", hello(){...}}，调用 hello 打印 this.name。

第8章 数组

数组是排成一排的盒子，从 0 开始编号。

const nums = [10, 20, 30];
console.log(nums[0]);     // 10
console.log(nums.length); // 3

nums.push(40);   // 加到末尾
console.log(nums);        // [10, 20, 30, 40]

nums.pop();               // 删末尾
console.log(nums);        // [10, 20, 30]

常用方法

const nums = [3, 1, 4, 1, 5];

nums.indexOf(4);         // 2，找位置
nums.includes(3);        // true，是否包含
nums.slice(1, 3);        // [1, 4]，切片
nums.concat([9, 2]);     // [3,1,4,1,5,9,2]，合并
nums.sort();             // [1,1,3,4,5]，排序
nums.reverse();          // [5,4,3,1,1]，反转
nums.join("-");          // "3-1-4-1-5"，拼成字符串

数组三件套

const nums = [1, 2, 3, 4];

// map：转换每个元素
const doubled = nums.map(n => n * 2);
console.log(doubled);  // [2, 4, 6, 8]

// filter：筛选符合条件的
const evens = nums.filter(n => n % 2 === 0);
console.log(evens);    // [2, 4]

// reduce：汇总成一个值
const sum = nums.reduce((acc, n) => acc + n, 0);
console.log(sum);      // 10
通讯里最常用从 API 拿到一堆数据，用 map 转换，用 filter 筛选，用 reduce 统计。你发来的 app.js 里全是这三个。

find

const users = [
  { id: 1, name: "A" },
  { id: 2, name: "B" }
];
const u = users.find(x => x.id === 2);
console.log(u.name); // "B"
纸上练习1. 用 filter 筛出 [1,2,3,4,5] 里大于 3 的数。2. 用 map 把每个数变成平方。3. 用 reduce 求 [1,2,3,4,5] 的和。

第9章 对象

对象是一堆数据，每个格子有名字，不只是编号。

const user = {
  name: "小明",
  age: 13,
  city: "北京"
};

console.log(user.name);     // "小明"
console.log(user["age"]);   // 13

user.age = 14;              // 改属性
user.email = "a@b.com";     // 加新属性
delete user.city;           // 删属性

解构

const { name, age } = user;
console.log(name); // "小明"
console.log(age);  // 13

// 重命名
const { name: userName } = user;
console.log(userName); // "小明"

// 默认值
const { phone = "无" } = user;
console.log(phone); // "无"

展开运算符

const copy = { ...user, city: "上海" };
console.log(copy.city); // "上海"
// 原来的 user 没变

const merged = { ...user, ...copy };
// 后面的覆盖前面的

方法

const user = {
  name: "小明",
  greet() {
    return "你好，" + this.name;
  }
};
console.log(user.greet()); // "你好，小明"
纸上练习1. 创建一个对象包含你的名字、年龄、食物。2. 用解构拿出名字。3. 用 ... 复制它并改城市。

第10章 JSON

电脑之间传数据，不能直接传对象。要先把对象变成字符串，传过去再变回来。

对象 ↔ 字符串

const user = { name: "小明", age: 13 };

// 对象 → 字符串
const str = JSON.stringify(user);
console.log(str); // '{"name":"小明","age":13}'

// 字符串 → 对象
const obj = JSON.parse(str);
console.log(obj.name); // "小明"
通讯里最常用发请求前用 JSON.stringify 转字符串，收到回复后用 JSON.parse 转对象。localStorage 也只能存字符串。

JSON.parse 会报错

JSON.parse("不是JSON");
// 报错：Unexpected token 不 in JSON at position 0

所以要配合 try/catch（第15章讲）。

嵌套对象

const data = {
  user: { name: "小明" },
  posts: [{ id: 1, title: "你好" }]
};

const str = JSON.stringify(data);
const obj = JSON.parse(str);
console.log(obj.user.name);   // "小明"
console.log(obj.posts[0].title); // "你好"
纸上练习1. 把 {a:1, b:2} 用 JSON.stringify 转成字符串，写出来。2. 把这个字符串用 JSON.parse 转回对象，写下 .a 的值。

第11章 HTML / CSS / JS

一个网页由三样东西组成：

  • HTML：骨架。有什么东西。
  • CSS：皮肤。长什么样。
  • JavaScript：肌肉。能做什么。

完整模板

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width,initial-scale=1.0">
  <title>我的网页</title>
  <style>
    body { background: #f0f0f0; }
    h1 { color: red; }
  </style>
</head>
<body>
  <h1>你好</h1>
  <button id="btn">点我</button>

  <script>
    document.querySelector("#btn").onclick = () => {
      alert("你点了按钮");
    };
  </script>
</body>
</html>
关键<script> 放 <body> 底部。放 <head> 里，JS 执行时 HTML 还没读完，会找不到元素。

常用 HTML 标签

<h1>大标题</h1>
<p>段落</p>
<div>块，用来分组</div>
<span>行内小块</span>
<a href="网址">链接</a>
<img src="图片地址">
<input placeholder="输入框">
<button>按钮</button>
<ul><li>列表项</li></ul>

常用 CSS

选择器 { 属性: 值; }

body { background: #f0f0f0; }
.box { width: 100px; height: 50px; }
#title { color: red; font-size: 20px; }

. 开头是 class，# 开头是 id。class 可以多个元素用，id 只有一个。

第12章 DOM

DOM 是浏览器把 HTML 变成一棵可以操作的对象树。JS 通过 DOM 找到页面上的元素，改它。

找元素

document.querySelector("#btn");       // 找 id=btn 的第一个
document.querySelector(".item");      // 找 class=item 的第一个
document.querySelectorAll(".item");   // 找所有 class=item，返回列表
document.getElementById("btn");       // 找 id，老写法

改内容

// 安全：只显示文本
el.textContent = "新文字";

// 危险：会渲染 HTML，用户输入可能 XSS
el.innerHTML = "<b>粗体</b>";
XSS 安全提醒永远用 textContent 显示用户输入的内容。用 innerHTML 拼接用户输入，别人可以注入恶意脚本。

改样式

el.style.color = "red";
el.style.fontSize = "20px";
el.classList.add("active");
el.classList.remove("active");
el.classList.toggle("active");  // 有就删，没有就加

创建和删除

const li = document.createElement("li");
li.textContent = "新项目";
document.querySelector("ul").append(li);

li.remove();  // 删除

读属性

input.value;         // 输入框里的内容
a.href;              // 链接地址
img.src;             // 图片地址
纸上练习1. 写找 id="box" 的元素的代码。2. 写把它的文字改成“你好”的代码。3. 写创建一个 <p> 并加到 body 的代码。

第13章 事件

事件就是“用户做了什么”。点按钮、按键盘、滑鼠标，都是事件。

addEventListener

const btn = document.querySelector("#btn");

btn.addEventListener("click", () => {
  console.log("被点了");
});

第一个参数是事件名，第二个是回调函数。

常用事件

  • click 点击
  • input 输入框内容变化
  • keydown 按下键盘
  • submit 表单提交
  • change 选择框、复选框变化

键盘

input.addEventListener("keydown", (e) => {
  if (e.key === "Enter") {
    console.log("按了回车");
  }
});

e 是事件对象，包含 e.key、e.target 等信息。

事件委托

const ul = document.querySelector("ul");

ul.addEventListener("click", (e) => {
  if (e.target.tagName === "LI") {
    e.target.classList.toggle("done");
  }
});

把事件绑在父元素上，利用冒泡处理子元素。适合动态列表——新加的子元素不用再绑。

阻止默认行为

form.addEventListener("submit", (e) => {
  e.preventDefault();  // 阻止表单刷新页面
  console.log("提交了");
});
纸上练习1. 写一个按钮点击打印“你好”的代码。2. 写一个输入框按回车打印里面的内容。3. 用事件委托给 ul 绑定，点 li 时切换 done 类。

第14章 定时器与 localStorage

setTimeout：等一会儿执行一次

setTimeout(() => {
  console.log("1秒后执行");
}, 1000);

1000 是毫秒，等于 1 秒。

setInterval：每隔一会儿执行一次

const timer = setInterval(() => {
  console.log("每2秒打印一次");
}, 2000);

clearInterval(timer); // 想停的时候

第15章 错误处理

代码会出错。出错时如果不处理，页面就白了。用 try/catch 接住错误。

基本结构

try {
  // 可能出错的代码
  const data = JSON.parse("不是JSON");
} catch (err) {
  // 出错后干什么
  console.log("出错了：" + err.message);
} finally {
  // 不管成功失败都执行（可选）
  console.log("结束");
}
关键try 里放可能出错的代码，catch 里放出错后怎么办。err.message 是错误信息。

主动抛错

if (!res.ok) {
  throw new Error(`HTTP ${res.status}`);
}

throw 主动抛出一个错误，会被外面的 catch 接住。

结合 async/await

async function getData() {
  try {
    const res = await fetch("/api/data");
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.log("请求失败：" + err.message);
  }
}
不处理的后果错误不处理，后面的代码不会执行，用户看到白屏。所以关键的 fetch、JSON.parse、await 都要包在 try/catch 里。
纸上练习1. 写 try/catch 包住 JSON.parse("不是JSON")。2. 写出 catch 打印 err.message 的代码。

第16章 异步

有些事要等：等网络、等文件、等用户。JS 不能傻等，它用“异步”。

同步 vs 异步

console.log("1");

setTimeout(() => console.log("2"), 0);

console.log("3");

// 输出顺序：1 3 2

同步代码先跑完，异步的回调等一会儿再跑。这叫事件循环。

Promise

const p = fetch("/api/data");

p.then(res => res.json())
 .then(data => console.log(data))
 .catch(err => console.error(err));

Promise 三种状态：pending（进行中）、fulfilled（成功）、rejected（失败）。

async / await

async function getData() {
  const res = await fetch("/api/data");
  const data = await res.json();
  console.log(data);
}

await 就是“等它回来再往下走”。async 表示这个函数里有异步操作。

fetch 的坑fetch 遇到 404 不会自动报错。一定要手动判断 res.ok。

顺序问题

async function run() {
  console.log("A");
  await fetch("/api");
  console.log("B");  // 等 fetch 完才执行
}
run();
console.log("C");  // 先执行，因为 run 是异步的
// 输出：A C B

第18章 CORS

CORS 是浏览器的安全机制。你的网页不能随便请求另一个域名的数据，除非对方服务器允许。

报错长这样Access to fetch at '...' has been blocked by CORS policy

为什么会这样

浏览器怕你的网页偷偷把数据发给别的网站。所以跨域请求（你的域名 ≠ 请求的域名）默认被拦。

开发阶段：用 *

// Worker 里
const CORS = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
  "Access-Control-Allow-Headers": "Content-Type"
};

* 表示“任何网站都能调我”。开发方便，但不安全，谁都能刷你的接口。

生产阶段：白名单

const CORS = {
  "Access-Control-Allow-Origin": "https://你的域名.com",
  "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
  "Access-Control-Allow-Headers": "Content-Type"
};

只允许自己的域名。别人网站调你的接口会被浏览器拦。

OPTIONS 探路请求

跨域请求前，浏览器先发一个 OPTIONS 请求“探路”。服务器要回 CORS 头，浏览器才允许真正的请求。

if (request.method === "OPTIONS") {
  return new Response(null, { headers: CORS });
}
一句话记住开发用 *，上线改白名单。上线还用 * 等于门没锁。
纸上练习把 * 改成 https://chick.cc.cd，写出这行代码。

第19章 模块化

代码多了要拆文件。一个文件导出，另一个文件导入。

导出

// math.js
export function add(a, b) {
  return a + b;
}

export const PI = 3.14;

export default function multiply(a, b) {
  return a * b;
}

第21章 worker.js 导读

下面是你之前发来的 worker.js 的核心结构，重新贴一遍。

路由

var CORS = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
  "Access-Control-Allow-Headers": "Content-Type"
};

async function handle(request, env) {
  var url = new URL(request.url), path = url.pathname;

  if (request.method === "OPTIONS") {
    return new Response(null, { headers: CORS });
  }

  if (path === "/messages" && request.method === "GET") {
    // 拿消息
  }

  if (path === "/send" && request.method === "POST") {
    // 发消息
  }

  return new Response("Not Found", { status: 404 });
}

export default {
  async fetch(request, env) {
    return handle(request, env);
  }
};

request.url 是完整网址，url.pathname 是路径，request.method 是 GET/POST。

数据库

// 查：id 大于 since 的消息，倒序，最多 limit 条
var r = await env.DB.prepare(
  "SELECT id,name,content,type,time FROM messages WHERE id>? ORDER BY id DESC LIMIT ?"
).bind(since, parseInt(limit)).all();
// r.results 是数组

// 增：插入一条消息
await env.DB.prepare(
  "INSERT INTO messages (name,content,type,time) VALUES (?,?,?,?)"
).bind(name, content, type, time).run();
关键prepare 准备 SQL，? 是占位符，bind 填值，all() 拿多条，first() 拿一条，run() 执行增删改。
为什么不直接拼字符串如果你写 "SELECT * FROM messages WHERE id=" + id，别人输入 1 OR 1=1 就能拖走所有数据。这叫 SQL 注入。? + bind 能防。

第22章 app.js 导读

app.js 是一个单页应用。它用几个对象把代码分开了：

  • State：全局状态（当前用户、页面、token）
  • Utils：工具函数（toast、格式化、图片压缩、API 请求）
  • Pages：每个页面返回 HTML 字符串
  • Router：切换页面
  • App：业务逻辑（登录、搜索、下载、审核）

结构

const State = {
  currentUser: null,
  token: localStorage.getItem('chick_token') || null
};

const Router = {
  async go(page, param) {
    State.currentPage = page;
    const html = await Pages[page](param);
    document.getElementById('page-container').innerHTML = html;
  }
};
关键所有页面都是 JS 拼出来的 HTML 字符串，用 innerHTML 塞进页面。所以 app.js 里大量 `<div>...</div>` 模板字符串。

API 请求

async api(path, options = {}) {
  const opts = {
    headers: {
      'Content-Type': 'application/json',
      ...(State.token ? { 'Authorization': 'Bearer ' + State.token } : {})
    },
    ...options
  };
  if (options.body && typeof options.body === 'object') {
    opts.body = JSON.stringify(options.body);
  }
  const res = await fetch(API_BASE + path, opts);
  const data = await res.json();
  if (!res.ok) throw new Error(data.error || '请求失败');
  return data;
}
它干了什么自动加 Content-Type 和 Authorization，自动把对象转 JSON 字符串，自动检查 res.ok，出错抛异常。
安全问题app.js 里 State.token = user.id，把用户 id 当 token，等于没有认证。别人知道你的 id 就能冒充你。还有管理员密码 chickfor670 硬编码在前端，按 F12 就能看到。这些是真实项目里必须改的。

第23章 安全清单

这些是 AI 生成的代码里最常见的坑。读完这本，你要能一眼看出它们。

1. 密码不能明文存

// 错误
INSERT INTO users (password) VALUES ("123456")

// 正确：存哈希值
const hash = await bcrypt.hash(password, 10);
INSERT INTO users (password_hash) VALUES (hash)

2. Token 不能是用户 id

用 JWT 或随机字符串，服务端能验证。前端只存 token，不存用户 id 当凭证。

3. CORS 上线要改白名单

// 开发
"Access-Control-Allow-Origin": "*"

// 上线
"Access-Control-Allow-Origin": "https://你的域名.com"

4. 输入必须校验

const name = (b.name || "匿名").substring(0, 20);
const content = (b.content || "").substring(0, 500);

5. 用 textContent 不用 innerHTML

显示用户输入，永远用 textContent。用 innerHTML 会被 XSS。

6. SQL 用 ? 不用拼接

// 正确
env.DB.prepare("SELECT * FROM users WHERE id=?").bind(id)

// 错误
"SELECT * FROM users WHERE id=" + id

7. 分页 + 限流

不要一次拉全部数据。加 LIMIT，加频率限制，防止刷接口。

8. 管理员密码不能在前端

app.js 里 if (pwd === 'chickfor670') 这种写法，按 F12 就能看到。管理员验证必须在后端。

记住AI 写的代码默认能跑，但默认不安全。上线前对照这张清单过一遍。
